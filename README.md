# MapaFull Ramos — mapas offline

Pacotes de mapa (arquivos `.pmtiles`, um por estado) que o aplicativo **MapaFull Ramos** baixa para funcionar sem
internet, e o `catalogo.json` que lista país, regiões e estados com tamanho e versão de cada pacote.

Mapas © colaboradores do [OpenStreetMap](https://www.openstreetmap.org/copyright) (ODbL), no padrão OpenMapTiles.
O código do aplicativo não fica aqui.
